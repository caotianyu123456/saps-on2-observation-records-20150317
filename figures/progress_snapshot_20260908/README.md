# Representative observation figures — 2026-09-08 snapshot

This directory contains six lightweight PNGs selected for remote discussion:

- five tight DMSP–GUVI candidate pages (`obs_01` through `obs_05`);
- one independent F16 DMSP/SSUSI flagship proxy figure at approximately 08:59 UT.

The five tight pages are candidate-audit figures, not five confirmed SAPS events. They all come from one St. Patrick storm and use a plotting selection based on horizontal drift magnitude plus low GUVI O/N2. The F16 SSUSI figure is a separate case and its `135.6/LBHS` quantity is a relative O/N2-sensitive radiance-ratio proxy, not official column O/N2.
