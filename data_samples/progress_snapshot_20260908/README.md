# Progress evidence snapshot — 2026-09-08

This directory contains public-safe, small evidence tables used by `reports/SAPS_ON2_CURRENT_PROGRESS_20260908.md`.

## Contents

- `dmsp_guvi_time_tolerance_summary.csv`: nested 3/2/1/0.5 h screen counts.
- `dmsp_guvi_candidates_le_0p5h.csv`: all nine candidates surviving the 0.5 h screen.
- `tight_dmsp_guvi_figure_summary.csv`: sanitized scientific fields for the five plotted tight candidates; local file paths were removed.
- `samepass_ssusi_guvi_summary.csv`: sanitized fields for the five same-satellite/same-pass DMSP–SSUSI pages; `same pass` does not include GUVI.
- `f16_normalized_proxy_0900_summary.csv`: normalized flagship SSUSI radiance-ratio proxy result.
- `f16_normalized_proxy_method_note.md`: short method and interpretation boundary for the normalized proxy.
- `f16_ssusi_official_on2_0900_summary.csv`: official SSUSI ON2 availability check for the flagship window.
- `f16_ssusi_official_on2_0900_method_note.md`: interpretation boundary for the official ON2 check.
- `event_universe_expanded_2011_2015.csv`: 737 storm-phase/date analysis rows; these are not 737 independent storms.

The files are evidence snapshots, not a completed multi-event statistical data release. The five tight candidates are selected with horizontal drift magnitude and low GUVI O/N2; they have not all passed signed-westward, geometry, morphology, persistence, and auroral-boundary audits.
